# CURL COMMANDS

### 1. Test Web Server

```bash
curl http://127.0.0.1:8080
```

Sends an HTTP request to the local Nginx server and prints its response, usually the default welcome-page HTML.

### 2. Create a Network Device

```bash
curl --fail --silent --show-error \
  -X POST http://127.0.0.1:8080/api/devices \
  -H "Content-Type: application/json" \
  -d '{
    "hostname": "DIST-SW1",
    "management_ip": "192.168.30.11",
    "device_type": "switch",
    "location": "Head Office"
  }'
```

Sends an HTTP POST request to the FastAPI backend to register a new network device in the PostgreSQL inventory.

**Command breakdown:**

- `curl` — sends an HTTP request.
- `--fail` — returns a failure exit code for HTTP errors (status 400 and above).
- `--silent` — suppresses the progress meter.
- `--show-error` — displays errors even when silent mode is enabled.
- `-X POST` — specifies the HTTP POST method to create a resource.
- `http://127.0.0.1:8080/api/devices` — the device creation endpoint, accessed through Nginx.
- `-H "Content-Type: application/json"` — identifies the request body as JSON.
- `-d '...'` — supplies the JSON data describing the device.

**Request fields:**

| Field | Description | Example |
|---|---|---|
| `hostname` | Unique device name | `DIST-SW1` |
| `management_ip` | Unique management IP address | `192.168.30.11` |
| `device_type` | Type of network device | `switch` |
| `location` | Physical or logical location | `Head Office` |

The `status` field is optional and defaults to `active`.

**Expected response:**

The API should return a JSON object similar to this:

```json
{
  "id": 1,
  "hostname": "DIST-SW1",
  "management_ip": "192.168.30.11",
  "device_type": "switch",
  "location": "Head Office",
  "status": "active",
  "created_at": "2026-10-12T..."
}
```

The ID and timestamp are generated by the database; the timestamp shown here is illustrative.

**Important:** Sending the same hostname or management IP again returns HTTP `409 Conflict`. Invalid input is rejected by the API before insertion. This command creates an inventory record only; it does not configure a real switch.
